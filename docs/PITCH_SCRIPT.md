# Presentation Script for Last Mile Medicine

## 🎤 Opening (30 seconds)

"Hi everyone! Imagine this: It's 2 AM. Your child has a high fever. You rush to find medicine—but which pharmacy is open? Which one actually has it in stock? You waste precious time searching blindly.

**This is the problem we're solving.**"

---

## 🧩 Problem Statement (45 seconds)

"During medical emergencies, people waste critical time searching for medicines across multiple pharmacies.

Even with Google Maps, you can't tell:
- ✗ Which pharmacy has the medicine in stock
- ✗ Which store is open right now
- ✗ Whether delivery is available
- ✗ If cheaper generic alternatives exist

This causes:
- Delayed treatment
- Panic and confusion
- Especially dangerous at night or in rural areas

**There's no system that shows where the medicine actually IS—just where pharmacies are.**"

---

## 💡 Solution (1 minute)

"Introducing **Last Mile Medicine**—a smart medicine finder that transforms your phone into a healthcare access tool.

Instead of just showing pharmacy locations, we show **medicine availability intelligence**.

### How it works:

**For Users:**
1. Search medicine by name, photo, or upload prescription
2. See nearby pharmacies ranked by:
   - Distance
   - Open/closed status
   - Likelihood of stock
   - Delivery availability
3. Emergency mode instantly filters only open pharmacies
4. One-tap call or get directions

**For Pharmacies:**
- Simple dashboard to update stock with one tap
- Visibility boost when they keep info updated
- Later: integration with billing software

---

"Shows cheaper generic options. Saves money. Example: ₹35 → ₹30."

## 🏗️ Tech Stack (30 seconds)

"Built for rapid deployment and scale:

**Frontend:** React with Leaflet for interactive maps  
**Backend:** Node.js API with Express  
**Data:** JSON for MVP, upgradeable to MongoDB/Firebase  
**APIs:** OCR.space for prescription scanning, OpenStreetMap  

**Why this stack:**
- Fast development (built in 24 hours)
- Easily scalable
- Low infrastructure cost
- Works offline with PWA potential"

## 📋 Q&A Prep

### Expected Questions:

**Q: How do you verify stock accuracy?**
A: "Crowd-verification (users confirm stock), pharmacy reputation scores, and later integration with billing software."

**Q: What if pharmacies don't update stock?**
A: "Gamification: reliability scores, visibility boosts for active pharmacies, and automated reminders."

**Q: How is this different from Google Maps?**
A: "Maps show location. We show availability, hours, delivery, pricing, and generic alternatives."

**Q: Revenue model?**
A: "Pharmacy subscriptions, delivery partnerships, sponsored listings (ethical), and government contracts for health data."

**Q: What about data privacy?**
A: "We don't store medical records. Only search queries (anonymized) for improving service. GDPR-compliant in future."

**Q: Scalability concerns?**
A: "Built on proven tech (React, Node.js). Can handle millions of requests with cloud infrastructure and caching."
